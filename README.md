# EMI Calculator – Excel

## Overview
An Excel-based EMI Calculator that helps users calculate monthly loan installments, total interest payable, and total repayment amount.

## Features
- Monthly EMI calculation
- Total interest calculation
- Total repayment calculation
- Loan repayment estimation based on principal, interest rate, and tenure

## Tools Used
- Microsoft Excel
- Excel formulas

## Project File
`EMI Calculator.xlsx`

## Objective
To build a simple financial tool for understanding loan repayments and practicing Excel skills.
